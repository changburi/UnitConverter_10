## 2. 핵심 결정·산출물

### 2.1 Dual-Track pytest

| Track | 명령 | 결과 |
|-------|------|------|
| **A — Logic** | `python -m pytest tests/entity tests/control -v` | **3 passed** |
| **B — UI** | `python -m pytest tests/boundary -v` | **2 passed** |
| **전체** | `python -m pytest tests/ -v` | **11 passed** |

| Test ID | 파일 | 내용 |
|---------|------|------|
| D-LOC-01~03 | `tests/entity/test_d_loc_01.py` | `unit_convert` meter/feet/yard |
| U-IN-01~02 | `tests/boundary/test_u_in_01.py` | E001 · E003 메시지 |
| 레거시 6건 | `tests/test_converter.py` | CLI 통합 |

### 2.2 ECB 구현 (신규·수정)

| Layer | 파일 | 역할 |
|-------|------|------|
| entity | `conversion.py`, `constants.py` | `unit_convert`, `SUPPORTED_UNITS` SSOT |
| control | `validation.py`, `solver.py` | E001~E003 · `validate_number` (E002/E005) · 3줄 출력 |

### 2.3 GUI 데모

| 파일 | 역할 |
