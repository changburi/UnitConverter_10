# Mom Test 워크북 프롬프트 — UnitConverter_10

## 워크북 템플릿 요청

```
## Mom Test 워크북 — UnitConverter_10
### 페르소나:
### 인터뷰 답변 (과거 사실):
### 표면 문제 (금지 — 솔루션 섞인 문장):
### 진짜 문제 (한 문장):
```

---

## STEP 1 — Mom Test 인터뷰 프롬프트

```
UnitConverter_10 STEP 1 — Mom Test 인터뷰를 진행해.
너는 스타트업 멘토(Rob Fitzpatrick Mom Test 스타일)야.
나는 [UnitConverter를 손으로/코드로 다루는 학습자] 역할이야.
규칙:
1. 한 번에 질문 1개만
2. 금지: "만들면 좋겠어?", "이 기능 필요해?", "TDD 하면 어때?"
3. 허용: "마지막으로 ~했을 때", "그때 몇 분 걸렸어?", "뭐 때문에 포기했어?"
4. 내 답이 모호하면 추궁 1개만
5. 내가 솔루션 말하면 "그건 나중" 하고 불편으로 되돌려
먼저 인터뷰 질문 1번만 해. 솔루션 언급 금지
```

## 인터뷰 종료·정리 프롬프트

```
Mom Test 인터뷰 종료.
지금까지 답변:
[워크북 전체 붙여넣기]
다음만 출력:
1. 표면 문제 (잘못된 정의) — "~~프로그램 만든다" 류
2. 진짜 문제 (한 문장) — 불편·비용·판정·재현 중심, 솔루션 이름 없음
3. Mom Test 증거 3줄 (내 답에서 인용)
```

## Mom Test 규칙 요약 (참고)

| 구분 | 예시 |
|------|------|
| **금지** | "변환 앱 있으면 쓸 것 같아?", "이 기능 필요해?" |
| **허용** | "마지막으로 ~했을 때", "몇 분 걸렸어?", "왜 포기했어?" |
| **표면 문제** | 솔루션이 섞인 문장 ("~~프로그램 만든다") |
| **진짜 문제** | 과거 행동·비용·불편·재현 — 솔루션 이름 없음 |
